# Laboratorio de Balanzas

## Como funciona

1. Define el numero de jugadores y los cubos por color.
2. Inicia la partida.
3. En cada turno, el jugador arrastra cubos a los platos temporales izquierdo y derecho.
4. Presiona **Listo: confirmar movimiento** para mover esos cubos a la balanza seleccionada.
5. La balanza muestra solo la inclinacion, no la diferencia exacta de peso.
6. Puedes cambiar entre balanza principal y secundaria para hacer comparaciones.
7. Opcional: usa **Revelar 1 color al azar** una sola vez por partida para ver el peso real de un color.
8. Cuando quieras, usa **Adivinar pesos** para ingresar todos los valores.
9. Si todos son correctos, ganas; si no, la partida termina.
